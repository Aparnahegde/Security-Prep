**SSL (Secure Sockets Layer) **
 is deprecated because it has security weaknesses and TLS is safer.
 
Main reasons — easy to remember
1. Weak encryption: Older SSL versions support outdated cryptographic algorithms.
2. Security vulnerabilities: SSL has known flaws that attackers can exploit.
3. Man-in-the-middle attacks: Attackers may exploit weaknesses to interfere with secure communication.
